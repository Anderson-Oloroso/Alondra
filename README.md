# ¡Feliz Cumpleaños, Alondra! 💖🎂

Una página web romántica e interactiva diseñada como una **Carta de Amor y Celebración de Cumpleaños** para **Alondra**.

---

## ✨ Características Principales

- **💌 Carta de Amor Interactiva:** Sobre con sello de cera que se abre con animación y muestra una carta de amor en estilo pergamino vintage.
- **🎶 Música Romántica de Fondo:** Reproducción fluida y optimizada de la canción *"Seremos"* tanto en computadoras de escritorio como en celulares (iOS Safari y Android Chrome) respondiendo a gestos de toque/clic.
- **🎁 Módulo de Deseos de Cumpleaños:** Botón flotante especial con buenos deseos y palabras de amor para Alondra.
- **💖 Animaciones e Interacción:** Corazones que brotan al tocar o hacer clic en cualquier parte de la pantalla, pétalos flotantes, globos de cumpleaños y texto con efecto máquina de escribir.
- **📱 100% Responsivo:** Diseño totalmente adaptable para celulares, tablets y computadoras.

---

## 🚀 Uso y Visualización

Para ver la página en vivo:

1. Abre `index.html` en cualquier navegador web moderno (Chrome, Safari, Firefox, Edge).
2. Toca cualquier parte de la pantalla o el botón de música en la esquina inferior para iniciar la música de fondo.
3. Toca el sobre para desplegar la carta de amor.
4. Toca el botón de **Deseos de Cumpleaños** para ver las dedicatorias especiales.
